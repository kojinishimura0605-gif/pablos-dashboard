どんな仕組みか（1分でわかる全体像）

メンター・リーダー・クルー資格者限定の「メンバー名鑑」と「話したい申請」の場です。会員データはログイン後にのみ表示される設計で、ログイン前の公開ページには会員情報を置いていません。

入口UMU・決済でお使いのメールアドレスを入力 → 資格者リストとサーバー側で照合 → 一致した方にだけ6桁の確認コードをメール送付（パスワード不要）
名鑑プロフィール（写真つき）を資格別バッジで一覧・絞り込み。プロフィール充実度はAIが100点満点で採点
マッチング「この方と話したい」を申請 → 一次対応は運営スタッフ → 最終引き継ぎは事務局長の承認ゲート（勝手につながらない設計）
裏方資格者リストは顧客DBマスターから毎朝自動同期。資格を失った方は翌朝自動で入場不可に
設計思想：これは単なる名簿ではなく、100日ファン化計画の「養育→支持」フェーズを支える装置です。会員同士の推し活・相互発見が起きる場を運営の管理下でつくることで、1名の熱中者が周りを巻き込むベルトコンベアの終盤工程を担います。

実用化ロードマップ（ご提案）

  1. ログインの最終動作確認（即日可能）
    8/11以来の実測がないため、本日あらためて「メール入力→コード受信→ログイン成立」までを通しで検証します。
  2. 試運転：スタッフ・運営メンバーで開放（〜1週間）
    まず運営側の少人数でプロフィール登録と申請フローを一巡させ、使い勝手の引っかかりを潰します。
  3. 段階招待：メンター → リーダー → クルー
    資格の上位層から順にご案内します。上位層の登録が名鑑の「見応え」になり、後続の登録動機になります（呼び水設計）。
  4. 案内メールの配信（MyASPから・配信GOは承認制）
    「名鑑に登録すると何が起きるか」を一言で伝える案内文をドラフトし、ご承認後に配信します。
段階招待とする技術的な理由：ログイン用メールの無料枠が1日100通・1時間30通のため、357名へ一斉案内すると初日に確認コードが枠切れし「コードが届かない」体験を生むリスクがあります。段階招待なら無料枠内で安全に回せます。一斉開放をご希望の場合は送信サービスの有料プランへの切り替えで対応可能です（料金は決裁前に最新の公式価格を確認します）。
